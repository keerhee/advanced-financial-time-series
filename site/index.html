Practice data — you extract it

This course ships no data set. Every series the labs use is public, and pulling it yourself is the first exercise. One script does the whole job; six CSVs land in data_out/, and that is the entire data footprint of the sixteen weeks.

git clone https://github.com/keerhee/advanced-financial-time-series.git
cd advanced-financial-time-series/data
pip install -r requirements.txt
python fetch_data.py --end 2026-08-20

Pin the end date. The lab prompts say “to today”, which means no two students hold the same series and a number printed in March will not reproduce in May. Pass --end for anything you hand in, and quote the MANIFEST.json the script writes. Several weeks need no download at all — the nowcasting lab builds its own synthetic indicators on purpose, the simulation cases fix a seed, and every “Worked by Hand” case prints its numbers on the slide.

Both are places where the second unit opens by taking the first unit's conclusion as its premise. See the curriculum map for the full table and the exam scopes.
